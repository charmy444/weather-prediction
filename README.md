# Прогноз температуры на 7 дней

End-to-end проект по очистке погодных данных, анализу временных рядов и прогнозу температуры на 7 дней вперед для нескольких городов.

## Цель проекта

Построить воспроизводимый пайплайн для прогноза температуры по почасовым погодным данным:

- загрузить и очистить Excel-источник с проблемами качества данных;
- восстановить регулярную почасовую временную сетку;
- провести EDA и статистический анализ временных рядов;
- подготовить признаки для прогноза;
- обучить и сравнить несколько ML-моделей;
- подобрать гиперпараметры лучшей модели через Optuna.

## Данные

Источник данных: `some_fixes.xlsx`

Файл содержит несколько листов с погодными данными и искусственно/технически испорченными значениями:

- сломанная кодировка в названиях листов и городов;
- строковые значения вместо `NaN`;
- смешанные типы данных;
- пропуски;
- дубли по паре `city-ds`;
- выбросы в температуре, осадках и скорости ветра;
- пропущенные почасовые интервалы.

После объединения и нормализации используются данные по 6 городам:

- Благовещенск
- Геленджик
- Москва
- Находка
- Санкт-Петербург
- Сочи

Временной диапазон: `2019-01-01` - `2025-12-31`.

## Что сделано

### 1. Загрузка и очистка данных

- Загрузка Excel-файла через `openpyxl` и `pandas`.
- Исправление сломанной кодировки листов и городов.
- Объединение нескольких листов в единый датафрейм.
- Приведение строковых пропусков и смешанных типов к корректному числовому формату.
- Нормализация названий городов.

### 2. Контроль качества временного ряда

Проверены:

- дубли по `city-ds`;
- пропущенные почасовые интервалы;
- доля пропусков по признакам;
- равномерность временной сетки.

После проверки данные приведены к регулярной почасовой сетке.

### 3. Обработка пропусков и выбросов

- Дубли агрегированы по среднему значению.
- Для каждого города восстановлена полная почасовая временная сетка.
- Непрерывные признаки заполнены линейной интерполяцией внутри города.
- `weathercode` заполнен через forward/backward fill.
- Выбросы температуры обработаны через IQR-подход по городам.
- Аномальные значения осадков и скорости ветра заменены на пропуски и затем восстановлены.

### 4. EDA и статистический анализ

В ноутбуке проведены:

- визуализация временных рядов по городам;
- анализ температуры, осадков и скорости ветра;
- ACF/PACF для анализа автокорреляции;
- ADF и KPSS тесты для проверки стационарности;
- STL-декомпозиция дневной температуры на тренд, сезонность и остатки;
- корреляционный анализ погодных признаков.

### 5. Feature Engineering

Для прогноза температуры через 7 дней созданы признаки:

- лаги температуры: `1h`, `2h`, `6h`, `12h`, `24h`, `48h`, `72h`, `7d`, `30d`, `365d`;
- скользящие средние и стандартные отклонения за `24h`, `7d`, `30d`;
- календарные признаки: час, день недели, месяц, день года;
- циклические признаки для часа и дня года через `sin/cos`.

Целевой признак:

```text
target_7d = temperature_2m через 7 дней
```

### 7. Модели и подбор гиперпараметров

Обучены и сравнены модели:

- `DecisionTreeRegressor`
- `RandomForestRegressor`
- `CatBoostRegressor`
- `CatBoostRegressor` с подбором гиперпараметров через `Optuna`

Optuna использовалась для минимизации validation `MAE`. Чтобы ноутбук оставался быстрым и воспроизводимым, подбор выполняется на сэмпле train-данных и ограничен 10 trials.

Метрики:

- `MAE`
- `RMSE`
- `WAPE`
