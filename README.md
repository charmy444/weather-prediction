# Прогноз температуры

## Описание
Очистить Excel-файл с погодными данными и построить модели для прогноза температуры на 7 дней вперёд.

## Данные
- Формат: `.xlsx`
- Несколько городов
- Есть ошибки, пропуски, проблемы форматирования

## Задачи
1. Загрузка: `pandas`, `openpyxl`
2. Очистка:
   - единый временной индекс
   - обработка пропусков и выбросов
3. Анализ:
   - визуализация
   - стационарность
   - декомпозиция (тренд/сезонность)
   - спектральный анализ
4. Feature Engineering:
   - лаги, скользящие статистики
   - календарные признаки
5. Модели:
   - Decision Tree, Random Forest, Boosting
   - Optuna (подбор гиперпараметров)
   - стратегии: recursive / direct
6. Разделение:
   - train / val / test
7. Метрики:
   - MAE, MAPE, WAPE
   - Directional Accuracy, Directional R²
